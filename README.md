# 五代十国历史展示网站

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://dreamsoldierwang-spec.github.io/five-dynasties-ten-kingdoms/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

一个交互式的五代十国历史时期可视化网站，通过时间轴、地图和详细信息展示这一动荡历史时期的政权变迁。

![五代十国历史展示网站](https://img.shields.io/badge/五代十国-历史展示-orange)

## 🌟 功能特点

### 📅 时间轴浏览
- 可拖动的时间轴，覆盖 907-960 年
- 实时显示当前年份和时期
- 标记重大历史事件

### 🗺️ 历史地图
- 展示五代（后梁、后唐、后晋、后汉、后周）疆域变化
- 显示十国（吴、吴越、闽、楚、南汉、前蜀、后蜀、荆南、南唐、北汉）分布
- 包含契丹/辽等重要政权
- 交互式地图，可点击查看详情

### 👑 皇帝详细信息
每位皇帝都包含：
- 生卒年份
- 性格特点
- 详细生平
- 主要成就
- 历史趣闻

### 📊 政权列表
- 实时显示当前年份存在的所有政权
- 区分五代（中央政权）和十国（地方政权）
- 快速切换查看不同政权

## 🛠️ 本地运行

### 方式一：直接打开
1. 下载或克隆本仓库
2. 用浏览器打开 `index.html` 文件

### 方式二：使用本地服务器
```bash
# 使用 Python
python -m http.server 8080

# 或使用 Node.js
npx serve

# 然后访问 http://localhost:8080
```

## 📖 使用说明

1. **拖动时间轴**：底部的时间轴可以左右拖动，查看不同年份的历史状况
2. **点击地图**：点击地图上的国家区域，查看该政权的详细信息
3. **查看列表**：右侧面板显示当前年份存在的所有政权，点击可切换
4. **阅读详情**：中间面板显示当前选中政权的详细信息，包括皇帝生平、历史事件等
